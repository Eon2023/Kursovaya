# Симулятор планетной системы с поддержкой редактирования и обработки событий

**Студент:** Карелашвили Т.И, группа ПИ-51
**Дисциплина:** Программирование, 3 семестр

## Описание

Консольный и GUI-симулятор планетной системы: центральная звезда, планеты,
спутники, астероиды. Поддерживает добавление/редактирование тел, паузу,
масштабирование сцены, сохранение/загрузку состояния, журнал событий,
проверку правил (столкновения, допустимые расстояния, каскадное удаление).

## Технологии

- **C++** — ядро логики + консольный режим
- **C#** — ядро логики (совместимое с Unity) + GUI
- **Unity** — визуализация и анимация движения планет

## Структура

- `cpp-core/` — C++ ядро и консольный режим
- `csharp-core/` — C# ядро логики
- `unity/` — Unity-проект (визуализация)
- `docs/` — документация, отчёты
